# Telegram Serverless Welcome Bot

A small Pashto-language Telegram bot handler for Telegram BotFather Serverless.

## File

- `handlers/message.js` — sends a welcome message and a reply keyboard, then responds to each keyboard button.

## Setup

1. Open the `handlers/message.js` file and copy its code.
2. In your BotFather Serverless bot project, create or open `handlers/message.js`.
3. Paste and save the code.
4. Send `/start` to your bot to test the welcome message and keyboard.

## Reply keyboard

- 🎮 لوبې
- 🤝 ملګرتیا
- 👤 زما پروفایل
- ℹ️ زموږ په اړه

This is a minimal starter example. Test it in your BotFather Serverless environment before using it in a production bot.
